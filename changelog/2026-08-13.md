# 2026-08-13

## Changed

- 将 BSmart 输入框、选择框、方法参数及 Widget 循环数据源统一重构为共享的 `BSmartValue<T>` 结构化值。
- 更新按钮、图片和轮播元素的元数据类型与运行态解析逻辑，静态值和变量引用改为互斥保存。
- 移除 Smart 值对基本类型及双花括号模板字符串的历史兼容逻辑。
- 重构 BSmart 输入与选择组件的变量模式，共享可编辑变量路径控件，并将变量入口移出普通输入框 suffix。
- 修复变量列表键盘导航无法首尾循环，以及打开列表时未回显、展开并滚动定位当前变量的问题。
- 统一变量列表为单一活动高亮，文本切换到变量模式后改为手动展开变量下拉。
- 修复变量草稿未提交时覆盖原值的问题，并禁止空变量路径进入 Smart 模型。
- 修复 Input 从文本切换到变量模式时草稿被清空的问题。
- 同步 Developing Widget 引用文档与校验器，统一校验 Button、Image、Swiper、Loop 和方法参数的结构化 Smart 值。
- 为 BSelect 增加可复用的下拉底部扩展区，支持自定义 footer 动作并向插槽暴露当前选中值、选中项和关闭回调。
- 在基础设置页的主题下拉中加入“自定义主题”入口，并改为 option-like 的行样式展示。
- 修正 BSelect tips 区域的内边距回归为上下留白，避免下拉提示贴边显示。
- 归一化 BSelect 传入 ASelect 的绑定值，空值在内部统一转成 `undefined`，修复模板侧 `SelectValue` 类型报错。

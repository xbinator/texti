# 2026-08-02

## Removed

- 移除「黑白线稿「Manga Ink」」主题预设（`src/theme/presets/manga-ink.ts`），不再在主题选择器与 SettingsTool 的 `themePreset` 取值中暴露；`test/theme/preset-list.test.ts` 的 `REMOVED_THEME_PRESETS` 同步登记 `manga-ink` 防止回归。

## Changed

- BButton 和 Settings 根侧栏导航改用按钮专属边框 Token，默认主题保持无边框，Overworld 通过 `button.borderWidth` 与 `button.border` 显示 2px 像素边框。
- HeaderTab、默认布局欢迎入口和 BDropdownButton 普通态改用按钮专属边框/阴影 Token；显式 `outline` / `bordered` 语义仍保留可见边框。
- Ant Design 主题尺寸派生支持将 `rem` / `em` 自定义尺寸按 16px 基准归一为 number，避免 CSS 变量和 AntD 控件表现分裂。
- 全局主题字体和 Ant Design 输入框主题 reset 合并进 `src/assets/styles/reset.less`，移除独立的 theme font/input 样式入口。
- BSkill 预览外壳与文件树节点改用 surface/control/motion 主题 Token，补齐 Overworld 的边框、圆角与交互状态。
- 默认布局 Windows 窗口控制按钮改用 button/control/motion 主题 Token，并为 Overworld 阴影预留 token 间距。
- SettingsTool 的 `themePreset` 取值描述补充 `overworld` 预设（纸面/钴蓝天空/墨线像素边/苔藓绿）。
- 聊天输入框在手动选择会话工作区后，`@` 文件候选切换为当前工作区内的相对路径文件列表；默认工作区继续使用最近 Markdown 文件候选。
- 手动工作区 `@` 文件候选支持 `.gitignore`、隐藏/二进制媒体过滤、浅层优先扫描、结果缓存和最近文件优先排序，降低大仓库候选噪音。
- 重命名 `src/components/BChat/hooks/useWorkspaceFileMentions.ts` → `useWorkspaceMentions.ts`，同步更新 `UseWorkspaceFileMentionsOptions`/`UseWorkspaceFileMentionsReturn` 接口、`useWorkspaceFileMentions` 函数与 `useChatComposer.ts` 内 `workspaceFileMentions` 变量名，与 `workspaceMentionEnabled`、`sortWorkspaceMentions` 命名族保持一致；测试文件同步重命名。
- BSmart `@` 文件候选默认最多展示 100 条，搜索与排序后再应用上限，避免大工作区一次性渲染过多候选。
- BDropdownButton 改用 `BButton size="small" type="secondary"` 承载触发按钮，删除自绘的 hover/active/边框/阴影样式，图标统一 `size="16"`；BToolbar 同步移除对 `.b-dropdown-button` 的 `:deep` 样式覆盖，与全局按钮样式体系保持一致。
- HeaderTab 支持激活标签页滚动到标签栏可视区域：切换标签或初始渲染时，仅当激活标签未完全可见才按最小位移平滑滚动，已可见时不做任何滚动。

## Fixed

- 修复 BSmart `@` 文件候选与 `/` 命令候选在同一查询上下文同步后重置高亮项的问题，鼠标悬停后的方向键导航会从悬停项继续移动。
- 修复全局 Ant Design 输入框阴影覆盖误作用到 `borderless` AInput，导致命令面板搜索框出现外层输入壳与内层输入框双重焦点边框的问题。

- 修复 Provider 侧栏搜索去掉本地输入壳后缺少 flex 收缩约束，且测试仍按旧的本地圆角样式断言的问题。

# 2026-08-12

## Changed

- Rich 编辑器在已有跨源码行或跨块边界文本选区时按 `Ctrl+A` / `Cmd+A` 直接全选全文；单个 Markdown 物理行因视觉折行产生的选区先保持当前行选中，再次按下仍可继续向上全选。
- Rich 编辑器普通文本选区改由 CSS Custom Highlight 绘制，fallback 高亮不再使用阴影扩展，避免长文本视觉折行时在不同系统上出现间隙或重叠。
- Source 编辑器新增 `Ctrl+A` / `Cmd+A` 逐级全选逻辑，按物理行先选中当前源码行，再次按下全选全文，跨物理行或包含行尾换行的选区直接全文全选。

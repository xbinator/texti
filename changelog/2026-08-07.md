# 2026-08-07

## Added

- 支持应用界面大小设置，通过根字号控制 rem UI 缩放。

## Changed

- 将界面大小设置入口调整为数字输入框，并限制根字号输入范围。
- 新增构建期 px 转 rem 插件，应用 UI 源码继续按设计稿像素书写。
- 主题 CSS 变量和 Ant Design 尺寸 token 按 14px 设计基准参与界面缩放。
- 修正 Vite 端 TypeScript 配置对根目录构建插件的类型检查覆盖。
- 命令面板改为输入 `?` 选择 `model` / `chat` 命令，并支持 `model `、`chat ` 裸前缀进入对应选择。
- 修复 WebView 完整页面截图只在首屏扫描定位层，导致第二屏滚动后才显示或动态创建的 `fixed` / `sticky` 元素重复进入最终长图的问题。
- WebView 完整页面截图期间隐藏页面根滚动条和所有内部滚动容器滚动条，并在截图结束或失败后恢复。
- 修复页面顶部定位栏带有 CSS 过渡或动画时，完整页面截图的后续切片仍会重复截入顶部定位栏的问题。
- 移除 WebView 地址栏按钮的全部 tooltip。
- 将基础设置页的设置项行与 AI 工具权限面板抽离为本页局部组件，降低页面模板复杂度。
- 合并基础设置页「配色方案」与「界面」分区为「基本设置」分区，减少重复分区。

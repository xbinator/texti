# 2026-08-07

## Added

- 支持应用界面大小设置，通过根字号控制 rem UI 缩放。
- 支持基础设置页按系统展示默认中文字体族选项，仅覆盖默认 UI 字体。

## Changed

- 统一主题字体变量为 `--font-sans` 与 `--font-mono`，移除展示字体和输入框字体的独立变量。
- 将界面大小设置入口调整为数字输入框，并限制根字号输入范围。
- 新增构建期 px 转 rem 插件，应用 UI 源码继续按设计稿像素书写。
- 主题 CSS 变量和 Ant Design 尺寸 token 按 14px 设计基准参与界面缩放。
- 修正 Vite 端 TypeScript 配置对根目录构建插件的类型检查覆盖。
- 命令面板改为输入 `?` 选择 `model` / `chat` 命令，并支持 `model `、`chat ` 裸前缀进入对应选择。
- 修复 WebView 完整页面截图只在首屏扫描定位层，导致第二屏滚动后才显示或动态创建的 `fixed` / `sticky` 元素重复进入最终长图的问题。
- WebView 完整页面截图期间隐藏页面根滚动条和所有内部滚动容器滚动条，并在截图结束或失败后恢复。
- 修复页面顶部定位栏带有 CSS 过渡或动画时，完整页面截图的后续切片仍会重复截入顶部定位栏的问题。
- 移除 WebView 地址栏按钮的全部 tooltip。
- 将基础设置页的设置项行与 AI 工具权限面板抽离为本页局部组件，降低页面模板复杂度。
- 合并基础设置页「配色方案」与「界面」分区为「基本设置」分区，减少重复分区。
- 更新基础设置页源码结构相关测试断言，适配样式抽离至子组件与文案变更。
- 基础设置页新增「字体设置」分区，原字体样式设置项文案调整为「样式」，其跟随主题选项文案调整为「默认」，并补充对应测试用例。
- 将 Skill 导入包的单个资源解压后大小限制放宽至 10 MiB，并将 zip 资源超限提示改为可读大小格式。
- 将 ToolActivity 模板中内联访问的 `activity.state` 与 `activity.progress?.phase` 提取为本组件 computed，模板更简洁。
- 修正 app rem 缩放测试断言，根字号设置项文案断言由 `字体大小` 更新为当前 UI 的 `大小`。
- 放宽 `PORTABLE_RESOURCE_ID_PATTERN` 允许字符集，资源标识现可包含 `.`，并补充对应测试用例。
- 移除 Skill 包导入时的资源标识格式校验，仅保留 Windows 保留名称检查，并删除对应格式校验测试用例。
- 修复 BChat 普通管道 Shell 命令执行期间不显示实时 stdout/stderr 的问题，并为并发 Runtime 输出补充隔离与容量限制。
- 精简 BChat 工具活动区域，所有工具仅显示当前状态，并保留空闲工具的继续等待与停止控制。
- 修复 BChat 普通管道 Shell 的 LF 换行错位、spinner 中间帧闪烁和 Runtime 消息更新擦除临时终端态的问题；原始输出继续实时传输，终端画面改为有界稳定帧，并使用固定字符网格展示。
- 修复 BChat 普通管道 Shell 在进程 `exit` 后丢失 stdio 尾部、固定刷新边界短暂发布空画面、投影队列无限积压，以及孤立完成事件创建空终端状态的问题。
- 为 BChat 气泡片段内容折叠添加共享折叠动画。
- 优化共享折叠动画的高度帧切换、盒模型和透明度过渡，减少展开收起时的跳动感。
- 将 BChat 气泡片段标题图标收敛到 `BubblePart` 统一渲染，调用方仅传入动态图标状态。
- 将工具气泡原始数据代码展示组件迁移到 `BubblePartTool/ToolCode.vue`，移除旧的 `BubblePartToolCode` 目录。
- 修复 BChat 气泡片段收起动画末尾因内容外边距突然消失导致的顿挫。
- 修复 BChat 气泡片段展开动画因动画根元素带内边距和位移过渡导致的跳动感。
- 移除 BChat 气泡片段标题右侧折叠图标，改为标题 hover 时由左侧图标切换为折叠按钮。
- 将 BChat 工具活动状态优先作为工具气泡标题文案展示，并把空闲控制按钮内联到标题右侧，移除独立 `ToolActivity` 组件。

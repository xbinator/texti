# 2026-07-31

## Added

- 模型平台列表页点击卡片进入详情页时，使用 View Transition API 共享元素缩放转场：详情容器从被点击卡片的视口位置缩放展开填满内容区，列表页保持可见后淡出。新增 `src/views/settings/provider/hooks/useProviderTransition.ts` 封装触发逻辑。

## Changed

- `ProviderCard` 点击改为通过 `useProviderTransition` composable 触发带类型标记的视图过渡，并为根元素添加 `data-provider-id` 以备后续反向 morph。
- `detail.vue` 的 `provider` 与 `models` 初始值改为同步从 store 读取，使视图过渡新快照能立即捕获真实内容，避免 morph 期间显示 spinner。
- `.stylelintrc.cjs` 放行 `active-view-transition` / `active-view-transition-type` 伪类与 `view-transition-*` 伪元素。
- `src/views/settings/service-model/` 目录重命名为 `src/views/settings/serviceModel/`，同步更新路由与测试文件引用，测试目录 `test/views/settings/service-model/` 同步重命名。

# 2026-08-03

## Added

- 默认布局新增标签页快捷键：`Ctrl+W` 关闭当前标签并在最后一个标签关闭后回到欢迎页，`Ctrl+Tab` 按当前标签顺序循环切换下一个标签，并在快捷键帮助中展示窗口与标签页分组（`src/layouts/default/hooks/useTabShortcuts.ts`、`src/layouts/default/components/ShortcutsHelp.vue`）。
- 新增 `.env.production`，通过 `TIBIS_ENABLE_RELOAD_MENU=false` 明确关闭生产环境刷新菜单入口。
- BCommandPanel 新增 `> chat` 跳转命令与聊天历史 source：在命令面板输入 `> chat` 可按关键词搜索聊天会话，按日期（今天/昨天/MM-DD）分组展示，选中后经 `createChatPath` 跳转到对应会话页（`src/components/BCommandPanel/sources/chat.ts`、`sources/jump.ts`、`utils/query.ts`、`types.ts`、`index.vue`）。
- BCommandPanel 新增 `?` 命令提示 source：输入 `?` 时展示可用的 `>` 跳转项，引导用户发现命令语法（`src/components/BCommandPanel/sources/hint.ts`、`utils/query.ts`、`types.ts`、`index.vue`）。
- 全局快捷键 `Ctrl+P`/`Cmd+P` 打开命令面板最近记录视图：`src/constants/shortcuts.ts` 新增 `COMMAND_PANEL` 常量，`src/layouts/default/index.vue` 通过 `useShortcuts` 注册。
- BWidget 新增内置轻量 `swiper` 轮播图元素，支持多图地址/替代文本变量、填充模式、自动轮播间隔、动画时长、初始索引、循环播放、纵向滚动与指示器颜色/形状配置（`src/components/BWidget/elements/Swiper`）。

## Changed

- 新建文档快捷键从 `Ctrl+Alt+N` 调整为 `Ctrl+N`，与欢迎页「新建文档」入口复用同一套新建文档逻辑；Electron 系统菜单的 `Ctrl+W` 改为应用内关闭标签页动作，避免触发窗口关闭（`src/constants/shortcuts.ts`、`electron/main/modules/ui/menu.mts`、`src/hooks/useMenuAction/index.ts`）。
- Chat Runtime 模型流失败时改为先实时投影 assistant 错误终态，再广播唯一的 Runtime error 终态；Renderer 在终态消息事件缺失时会就地结束 assistant 与待处理工具 Part 的 loading，并在 Main 落盘失败时补做持久化。Runtime 请求控制器同时补齐通知异常回滚，默认多窗口广播按窗口隔离故障，避免 pending 请求、会话写锁或健康窗口被单点 IPC 异常阻塞（`electron/main/modules/chat/runtime/service.mts`、`electron/main/modules/chat/runtime/controllers`、`src/components/BChat/hooks/useChatWorkflow.ts`、`src/components/BChat/utils`、`types/chat-runtime.d.ts`）。
- WebView 模型上下文改为只保留通过快照校验的当前完整网页观察，历史读取使用轻量存根；`operate_webpage` 新增受长度约束的步骤反思、记忆和目标，当前执行输入、历史动作、结果、错误与 compaction 瞬时字段均增加发送侧白名单，Renderer bridge 继续只接收页面操作字段。
- 新增 WebView 历史观察裁剪与步骤记忆设计，明确模型上下文只保留当前完整网页快照，历史步骤改为受约束的反思、记忆、目标、动作与结果，并覆盖正常请求和上下文压缩路径（`docs/superpowers/specs/2026-08-03-webview-history-observation-design.md`）。
- Electron 系统菜单中的「重新加载」与「强制重新加载」改为仅在开发环境且布尔环境变量 `TIBIS_ENABLE_RELOAD_MENU` 开启时显示，同时移除刷新菜单与「打开最近的文件」的 `CmdOrCtrl+R` 绑定，让 `Ctrl/Cmd+R` 完全无效（`electron/main/modules/ui/menu.mts`、`electron/main/env.mts`、`src/constants/shortcuts.ts`）。
- BCommandPanel 搜索框交互简化：移除搜索图标与 `/` 键帽，改用「搜索最近历史记录...」占位文案，并在无输入时展示「输入"?"即可查看可用命令」提示（`src/components/BCommandPanel/index.vue`）。
- BCommandPanel 样式按项目规范改用 `&` 嵌套写法，将 `:focus-within`、`:deep(.ant-input)`、`:hover` 等伪类与组合选择器收入父选择器；BEM 修饰符（`--active`/`--current`/`--unsaved`）保持平铺，`&__xxx`/`&--xxx` 仍禁用（`src/components/BCommandPanel/index.vue`）。
- BWidget 轮播图元素移除画布内左右切换按钮，右侧图片配置改为可拖拽排序的条形项，并将「添加图片」移动到图片区块标题右侧（`src/components/BWidget/elements/Swiper`）。
- BWidget 轮播图图片条目支持点击标题后内联编辑，图片地址为空时不再展示“未设置图片地址”占位文案，条目详情区左侧内边距与其他方向保持一致，删除按钮改为 hover/focus 时显示并与折叠按钮交换位置（`src/components/BWidget/elements/Swiper/components/ImageItem.vue`）。
- BWidget 轮播图指示器形状新增「激活短线」，普通圆点与未激活项均显示 3px 圆点，激活项显示 10px 短线，并移除「添加图片」按钮 tooltip（`src/components/BWidget/elements/Swiper`）。
- BWidget 轮播图设置面板移除「添加图片」按钮上的 `widget-swiper-setter__add` class，测试改为通过图片区块 extra 插槽定位按钮（`src/components/BWidget/elements/Swiper/Setter.vue`）。
- developing-widget 技能的元素与绑定参考补充 `swiper` 元素 metadata、指示器形状与图片资源说明（`skills/developing-widget/references/elements-and-bindings.md`）。
- BWidget 空白画布右键时也展示右键菜单，无选区时复制、层级、删除等选区相关操作保持禁用（`src/components/BWidget/index.vue`）。
- WebView DOM 检查看板「元素」区块右侧新增相机图标的选中元素截图按钮，复用现有选中元素截图流程（`src/views/webview/web/components/InspectorPanel.vue`、`src/views/webview/web/index.vue`）。

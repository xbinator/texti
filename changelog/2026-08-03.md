# 2026-08-03

## Added

- BCommandPanel 新增 `> chat` 跳转命令与聊天历史 source：在命令面板输入 `> chat` 可按关键词搜索聊天会话，按日期（今天/昨天/MM-DD）分组展示，选中后经 `createChatPath` 跳转到对应会话页（`src/components/BCommandPanel/sources/chat.ts`、`sources/jump.ts`、`utils/query.ts`、`types.ts`、`index.vue`）。
- BCommandPanel 新增 `?` 命令提示 source：输入 `?` 时展示可用的 `>` 跳转项，引导用户发现命令语法（`src/components/BCommandPanel/sources/hint.ts`、`utils/query.ts`、`types.ts`、`index.vue`）。
- 全局快捷键 `Ctrl+P`/`Cmd+P` 打开命令面板最近记录视图：`src/constants/shortcuts.ts` 新增 `COMMAND_PANEL` 常量，`src/layouts/default/index.vue` 通过 `useShortcuts` 注册。

## Changed

- BCommandPanel 搜索框交互简化：移除搜索图标与 `/` 键帽，改用「搜索最近历史记录...」占位文案，并在无输入时展示「输入"?"即可查看可用命令」提示（`src/components/BCommandPanel/index.vue`）。
- BCommandPanel 样式按项目规范改用 `&` 嵌套写法，将 `:focus-within`、`:deep(.ant-input)`、`:hover` 等伪类与组合选择器收入父选择器；BEM 修饰符（`--active`/`--current`/`--unsaved`）保持平铺，`&__xxx`/`&--xxx` 仍禁用（`src/components/BCommandPanel/index.vue`）。

## Removed

- 移除命令面板搜索框的搜索图标（`BIcon icon="lucide:search"`）与 `/` keycap 元素，及对应的 `.b-command-panel__search-icon`、`.b-command-panel__search-keycap` 样式与 keycap Token 引用（`src/components/BCommandPanel/index.vue`）。

## Test

- `test/components/BCommandPanel/sources.test.ts` 新增 chat source（会话搜索、分组、选中跳转、空结果）与 hint source（单一 `>` 跳转项）用例，并补充 jump source 对 `chat` 命令的过滤断言。

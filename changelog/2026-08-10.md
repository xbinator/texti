# 2026-08-10

## Added

- 新增主题开发指南，说明 `src/theme` 预设注册、Token 派生、Ant Design/Monaco 映射和测试检查流程。

## Changed

- 主题名称与描述改由各预设直接注册，设置键和通用说明抽为共享定义；SettingsTool 通过运行时快照发现并校验内置及用户自定义主题。
- README 下载说明补充 macOS 解除隔离属性命令，便于处理首次打开拦截。
- HeaderTab 关闭按钮改为鼠标移入时带不透明底色悬浮显示，放大关闭图标，遮住标题末尾且不再占用标签页布局空间。
- HeaderTab 关闭按钮样式测试改为识别 Less 嵌套规则，避免源码断言误匹配状态选择器。
- HeaderTab 脏状态标题增加警告色，并将未保存标记移动到标题文本之后。
- BMessage Markdown 表格增加宽度约束与内部横向滚动，避免宽表格撑开消息父容器。
- BMessage Markdown 表格单元格按容器宽度限制超长内容展示，父级变宽时上限同步放大。
- BMessage Markdown 表格增加复制按钮，支持将表格内容复制为 TSV 文本。
- BMessage Markdown 表格复制按钮改为黏性工具栏定位，并与表头行垂直居中。
- BChat 流式消息改为小型增量事件与合并后的耐久快照双通道，限制同步批次、模型输出和连续模型步骤，降低高频返回时的主进程写库、IPC 与 Renderer 全量替换压力。
- BMessage 大型 Markdown 改为共享 Worker 单飞解析，增加体积、嵌套、超时、取消和异常纯文本降级，避免旧结果、任务堆积或解析失败造成界面假卡死。
- Shell 高频输出按顺序合并并设置同步批次上限；强制最终回答改为跨分片有界协议过滤，工具输入只在完整边界解析。
- `write_file` 与 `edit_file` 工具卡片仅展示目标文件名和路径，不再显示写入内容、替换文本、原始输入或结果正文。
- 将 BChat Provider 流观察、工具步骤、历史竞争与实时 mutation 拆分为独立边界，并修正资源计量对重复非循环引用的误判。
- 完善内存与资源生命周期：主进程原生资源按渲染器所有者释放，长期缓存与任务墓碑设置固定上限，并在组件销毁时终止 Worker、定时器、轮询、RAF、延迟回调与全局监听。
- Rich 编辑器恢复间隙光标并将相邻表格间的标记上移为前一个表格末尾的竖向细光标，支持在表格之间插入空行。
- WebView AI 操作将 `snapshotId` 声明为必填字符串参数（导航传空字符串），同步校验步骤记忆，并通过快照单次消费、读写互斥、世代校验与主框架导航即时失效避免旧快照被遗漏、复用或竞态写回。

# 2026-08-06

## Changed
- 修复 BWidget 选中组合后从子节点拖拽时，Selecto 框选在释放鼠标后把选区覆盖成子元素的问题
- BWidget 选中组合后从子节点直接拖拽时保留 Moveable 控制点，并随拖拽预览刷新控制框
- LogFilterBar 样式改为 `&` 嵌套写法，减少 `.log-filter-bar` 父选择器重复，编译结果保持一致
- SchemaTreeEditor 中 `__name-input`、`__type-select`、`__description` 的 `:deep` 规则改为嵌套写法，消除父选择器重复
- `src/hooks/useChat/lib` 目录重命名为 `tool`，`useChatContextRegistry.ts` 重命名为 `useContextRegistry.ts`，同步更新所有引用与文档
- `src/hooks/useChat/tool` 目录重命名为 `context`，同步更新 `useContextRegistry.ts`、测试与文档中的全部引用
- Chat Runtime 新增用户级当前环境上下文，注入操作系统、时区、日期、具体时间、工作区、当前页面和当前文件定位信息，并将记忆上下文从 system prompt 移入 runtime context
- Editor 与 Widget 页面不再注册 `read_current_document` / `read_current_widget` 读取工具，改为通过页面自注册提供轻量环境信息
- WebView 页面工具 `operate_webpage` 重命名为 `operate_current_webpage`，并保留 `read_current_webpage` 读取能力
- 更新 AI 工具开发指南和页面工具自注册设计文档，说明页面工具与页面环境上下文的最新边界
- 移除 `shared/ai/tools/EnvironmentTool` 和 `get_current_time` 工具，当前日期、具体时间、时区等环境信息统一由 Chat Runtime 环境上下文提供
- Runtime 当前环境上下文新增具体时间字段，`useRuntimeEnvironmentContext` 重命名为 `useRuntimeEnvironment`，并拆分 Chat Runtime 请求配置准备逻辑以提升可读性
- 页面环境上下文改为由各页面组装自描述 `sections`，BChat 与 Runtime 不再硬编码 `currentPage` / `currentFile` 字段
- Widget 标签页图标统一改为 `lucide:blocks`，避免显示 `widget.json` 文件图标

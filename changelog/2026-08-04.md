# 2026-08-04

## Changed

- 项目级 pnpm 配置显式使用官方 npm registry，依赖升级查询与安装默认走 `https://registry.npmjs.org/`。
- 升级同主版本直接依赖并刷新锁文件，覆盖 AI SDK、MCP SDK、TipTap、CodeMirror、Vue/Vite/Vitest、UnoCSS、Stylelint Vue 配置链等依赖。
- 删除未直接使用的依赖声明，移除旧 Tavily/axios/form-data 显式闭包、未接入的 auto-import/p-limit/js-beautify、未使用的 TipTap BubbleMenu 扩展和冗余 Stylelint Vue/SCSS 配置链。
- AI 模块说明同步 Chat Runtime 长任务活性策略：移除固定 300 秒任务上限，明确模型停滞、工具无响应、无进展提醒、等待状态、MCP 兼容窗口与非 Runtime 直接调用的差异化边界（`docs/code-wiki/07-ai.md`）。
- 拆分 BubblePartTool 工具气泡组件，将活动状态、Shell 终端、提问结果和摘要展示从入口组件中独立出来，入口保留展示派生逻辑。
- 补充 grep 与 read_directory 工具结果摘要样式，成功结果展示为可读文本和信息标签，不再回退到原始 JSON。
- 补齐 glob、delegate_task、open_widget、stage_file_write、stage_file_edit 与 ask_user_choice 的工具气泡标题别名。

## Fixed

- 完成长任务活性实现的逆向故障审计：修复恢复查询遗漏、重复请求控制器竞态、Watchdog 非法输入与投影异常、Renderer 进度队列失控、工具终态残留活动、结构化取消错误丢失、子进程取消清理失败、Shell Runtime 固定时限及晚到事件复活等边界问题。
- MCP 按需连接现在完整传播取消并释放连接中的客户端；连接尾部失败不会留下已关闭会话，成功或超时后的迟到 progress 不再创建孤立 Watchdog。
- MCP 的 `toolCallTimeoutMs` 重新用于非 Runtime 直接调用的固定边界；Chat Runtime 不读取该固定时限，继续由 60 秒兼容观察期与进度 Watchdog 管理长任务。

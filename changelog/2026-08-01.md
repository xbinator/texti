# 2026-08-01

## Added

- 聊天消息 IPC 增加单条删除能力，用于在不覆盖活动流历史的前提下精确清理旧版本误写的恢复提示。
- BSkill 文件预览支持按扩展名自动语法高亮，复用 lowlight 与 BMessage 高亮器；新增 `src/components/BSkill/utils/languageDetect.ts` 扩展名语言推断工具。
- 新增复古冒险「Overworld」主题预设，覆盖纸面背景、钴蓝主色、墨线边框、像素字体栈和强风格控件 Token。
- 新增 Overworld 主题视觉 QA checklist，用于后续人工检查聊天、设置、编辑器与弹层的强风格一致性。

## Changed

- 聊天会话删除统一增加确认流程；运行中删除会先终止 Main Runtime 与 Child Checkpoint，并由主进程锁断言阻止未收敛删除。
- 补齐聊天侧边栏 Runtime 状态投影，删除按钮在所有运行状态下保持可用且不使用禁用属性。
- 聊天会话历史增加运行中与等待操作状态图标，并按运行、等待和其他状态显示对应的删除确认文案。
- Renderer 本地确认也会将会话投影为等待状态；同一会话存在多个并发确认时，需全部处理后才恢复运行状态。
- `src/components/BSkill/index.vue` 成功状态分支按 200KB 阈值切换纯文本/语法高亮渲染，引入局部 `CodeHighlightNode` 递归组件并通过 `@import` 复用 `.code-highlight()` mixin 套色。
- `src/assets/styles/markdown.less` 的 `.code-highlight()` mixin 补全 Markdown 常见 scope 类名（`hljs-section`/`hljs-bullet`/`hljs-code`/`hljs-emphasis`/`hljs-strong`/`hljs-link`/`hljs-quote`），使 BMessage、BEditor、BSkill 的 markdown 代码块着色完整。
- 主题系统从单纯颜色 Token 扩展为设计 Token contract，支持圆角、边框宽度、字体、动效和基础控件语义 Token 派生到 CSS 变量与 Ant Design。
- 分段控件、工具栏菜单、命令面板与智能选择控件接入主题设计 Token，圆角与动效跟随当前主题风格。
- 聊天输入区、消息附件、确认底板、会话历史、模型选择器和问题卡片接入主题设计 Token，减少 Overworld 等强风格主题的现代圆角残留。
- 已迁移的按钮、下拉、分段控件、工具栏、智能选择和聊天外壳改用语义边框宽度 Token，使 Overworld 的 2px 像素边框能从主题配置生效。
- 全局文本、代码文本、按钮和下拉按钮开始消费主题字体 Token，使 Overworld 字体栈能通过主题变量影响高频控件。
- 交互 Token 新增 raised/pressed shadow，并让按钮、下拉按钮和问题卡片消费按压位移与硬阴影，补齐 Overworld 的复古按压反馈。
- Ant Design 主题派生新增组件级 Token，Button、Input、Select、Modal、Drawer、Dropdown、Segmented 和 Tooltip 跟随主题圆角、边框宽度与字体语义。
- 输入框主题契约扩展为可独立配置圆角、边框宽度、内边距、字体、placeholder、图标、阴影和 keycap 样式；Overworld 输入框新增厚墨线、纸面底、硬阴影和像素快捷键提示语义，输入高度仍由各组件场景自行控制。
- 智能编辑器、图片预览、Todo 面板、Agent 通知、Toast 和聊天 BubblePart 系列接入主题圆角、边框宽度与动效 Token。
- Settings 与 Provider 页面外壳、卡片、模型列表、侧边栏项和搜索输入接入主题设计 Token，强风格主题在设置页保持一致。
- 主题注册表新增 schema version 为 1 的自定义主题注册入口，支持基于默认主题合并部分 Token 覆盖。
- Markdown 渲染层、旧消息气泡、编辑器深层块、Widget/Webview 面板、Color/Image/JSON viewer 等深层 chrome 接入语义圆角、边框、字体与动效 Token，减少 Overworld 下的现代样式残留。
- 默认布局、欢迎/聊天/技能/设置/Widget 页面、settings tools、Webview element picker 注入层完成页面级主题 Token 迁移，使页面外壳和导航 chrome 统一跟随 Overworld 及未来自定义主题。
- 命令面板搜索、聊天 composer、SmartEditor/SmartInput、Provider 搜索、模型搜索、Webview 地址栏、MCP ServerEditor、Monaco 弹窗、FindBar 和记忆输入框接入输入框 Token，强风格主题的输入体验不再依赖单点样式。
- Ant Design 的 Input、InputNumber、Picker 和 Select selector 增加全局输入阴影覆盖，Select focused/open 态使用更高特异性清除默认 glow，使 Overworld 的默认黑色硬阴影和聚焦 cobalt 硬阴影也能作用到 AInput/ASelect。
- Provider 侧栏搜索补齐输入框边框、圆角和硬阴影 Token，保持与全局输入主题一致。
- BButton 统一增加主题边框并接入独立按钮阴影 Token；Overworld 输入、按钮和交互硬阴影统一为 2px 2px，HeaderTab 与 Settings 侧边栏导航改用按钮阴影 Token。
- BDropdownButton 默认态补齐主题边框，避免只有 `bordered` 分支显示像素边框。
- BButton 按下态新增独立 pressed shadow Token；Overworld 按压位移改为 2px 且按下阴影归零，使按钮按下时贴平显示。
- HeaderTabs 内部标签页补齐按下动画；默认布局欢迎页 `lucide:blocks` 控件改为原生 HeaderTab 风格按钮，不再复用 BButton。
- Settings 根侧栏导航恢复原生元素实现，同时保留按钮体系的边框、阴影、激活和按下交互 Token。

## Fixed

- 修复默认布局关闭 ChatSider 后隐藏的 splitter 内容、拖拽线和 idle transform 仍可能贡献横向 scrollWidth，可见态外部 `margin-left` 增加整体 flex 宽度，以及默认布局缺少横向裁剪边界，导致 Overworld 硬阴影输入控件让页面出现右侧空白滚动区域的问题。
- 修复 BSelect 聚焦或展开时仍可能被 Ant Design selector focus glow 覆盖，导致 Overworld 输入框焦点阴影不一致的问题。
- 修复普通 Vitest 测试与当前组件契约不一致的问题：CSS 规则读取改为精确选择器匹配，默认布局 ChatSider 测试改为校验 `ref` 暴露的 `startMotion` 调用，MessageBubble agent 片段替身同步为 `BubblePartAgent`。
- 修复切换并重新打开仍在流式生成的会话时，未完成 assistant 草稿被误判为硬中断并新增“已中断”提示的问题；恢复前现在同时检查活动 Runtime 与 Agent Checkpoint，并在状态查询失败时保守保留草稿。
- 修复快速执行 A→B→A 会话切换时，第一次 A 的旧历史响应覆盖第二次 A 最新消息的问题。
- 活动 Runtime 重新接管会话时会识别并删除旧版本已持久化的伪硬中断提示，同时保留真正的用户中止记录。
- 修复会话切换后旧异步预检恢复执行、预检 loading 未及时释放，以及空白草稿重置后仍可能启动 Runtime 的问题。
- 修复请求预检期间切换 WebView 或编辑器时，能力描述与 Runtime 绑定到新资源的问题；资源身份现在从预检开始即冻结，后台工具只访问该 Runtime 的固定资源。
- 修复后台 Runtime 启动失败错误落到当前可见会话、再生成在破坏性持久化后因切页停止的问题。
- 修复确认决议 IPC 失败后界面永久消失、记忆授权失败后无可见降级、终态确认被重复提交，以及并发确认缓存相互覆盖的问题。
- 修复恢复阶段首次重放失败后不再重试，以及跳过失败请求继续执行后续请求导致原始顺序被破坏的问题。
- 修复删除会话后 Renderer Actor、Runtime 路由、能力与确认缓存残留的问题；显式 Session 已删除时，Main 会拒绝迟到的 Runtime 启动，防止产生孤儿消息。
- 修复会话删除成功但 fallback 导航被阻止时仍保留陈旧标签与 Runtime 投影的问题。
- Agent confirmation 终态游标改为最多保留最近 512 个，并将权威恢复中消失的 pending 请求终态化，避免游标长期无界增长和迟到事件复活。
- Runtime 恢复在第二份权威快照重放失败后增加 50ms、100ms 两次有界退避，同时保持请求原始顺序并在耗尽后抛出最后错误。
- 修复 BSkill 预览 Markdown frontmatter 被误判为标题、Shell 脚本走 shell session 语法导致高亮异常的问题，并补全 YAML、Bash、JSON、CSS、Diff 等常见 lowlight scope 配色。

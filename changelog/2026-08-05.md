# 2026-08-05

## Changed

- 将环境变量示例文件恢复为可跟踪的 `.env.production`，确保生产环境刷新菜单开关文件与测试读取路径一致。
- MCP Server 编辑器保存用户提交的原始 JSON 文本，编辑回显时不再重写 `mcpServers` 包裹、字段顺序和额外字段。
- MCP Server 原始 JSON 仅用于设置页回显，不再进入聊天 runtime 请求、Electron 重启请求或 `get_mcp_settings` 工具返回值。
- MCP Server 编辑器拒绝一次性提交多个 `mcpServers`，避免静默只保存第一个 server。
- 修复 Rich 编辑器选区引用在行内代码、强调和链接语法下无法映射 Markdown 真实物理行号的问题。
- 调整 Rich 选区引用的行号失败策略：原始 Markdown 存在但无法精确对齐时生成无行号引用，避免回退到错误的渲染坐标。
- 统一 Rich 解析与源码映射的行内语义，覆盖引用链接、HTML 实体、安全行内 HTML、批注、图片、数学公式及嵌套格式。
- 改为按物理源码文本行双向对齐 Rich 位置，修复 CRLF、开头连续空行、围栏代码、引用、列表、嵌套表格和表格硬换行的偏移问题。
- Markdown 原文存在时，正向与反向映射均采用失败关闭策略，不再混用可能过期的 parser attrs 行号。
- 新增 109 组结构场景的正反向映射矩阵，以及错误回退、CRLF 和第 99 行问题的专项回归测试。
- 将 Editor、WebView、Widget 的 ChatRuntime 页面上下文收敛到 `useChatContextProvider` 注册机制，页面通过同名 `useChatContext` provider 接入，BChat 通过通用 binding 发现工具与分发 Bridge，同时保留后台 Runtime 的资源隔离。
- 将 `ChatRuntimeCapabilityDescriptor` 的页面专用字段收敛为通用 `toolContext` binding，Runtime 恢复不再依赖具体页面类型。
- 补强页面工具注册的 KeepAlive 失活隔离、动态隐藏策略、跨来源重名检测、捕获 executor 的注销保护，以及嵌套稳定错误码透传。
- 将 Editor、WebView、Widget 页面工具的定义、真实执行、确认、展示与历史策略完整收归各自 `useChatContext`，BChat 不再维护页面类型或页面工具名。
- 删除 `shared/ai/tools` 中的 WebView/Widget 页面工具和 Electron WebView 专用执行、校验、历史投影分支；`DocumentTool` 仅保留应用级 `create_document`。
- Runtime 以通用 Renderer 工具描述符冻结 allowlist 和声明式 history，支持未知第四页面零中心配置接入。
- 页面工具执行独立转发 Runtime ID、中断信号与活动上报器，并增加可结构化克隆校验、元数据漂移防护、歧义展示回退和摘要异常降级。
- 更新 AI 工具开发指南，补充页面 `useChatContext` 自注册流程、权限与确认、展示与历史、中断处理、零中心配置检查和阅读路径。
- 修复命令式提示/输入弹窗通过关闭按钮、遮罩或 Esc 关闭时不结算 Promise，导致编辑器重命名取消后保存暂停不恢复的问题。
- Markdown 编辑器改为在初始文件加载完成后挂载，避免磁盘内容进入撤销栈并被 `Ctrl+Z` 撤销为空白。
- 修复 Graphite 深色主题下 BButton primary 按钮复用浅色主色导致背景发白的问题，改为按钮专属填充色 Token。
- BWidget 缩放百分比按钮改为按页面可视画布区域动态适配当前内容并居中展示，缩放结果仍限制在全局上下限内。

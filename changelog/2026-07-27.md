# 2026-07-27

## Changed
- `src/components/BEditor/panes/PaneRichEditor.vue` 的 `selectLineRange` 改用 `commands` 风格替代 `chain()`，每步独立 dispatch，语义清晰
- 选区滚动行为由 Tiptap 内置 `scrollIntoView`（默认滚动到最近边）改为复用宿主注入的居中滚动回调，将选区起始位置滚动到编辑器可视区域中间
- `selectLineRange` 调用 `focus(null, { scrollIntoView: false })` 聚焦编辑器，禁用 focus 内部 `scrollIntoView` 避免覆盖居中滚动位置
- 新增 `scrollRangeStartIntoCenter` 辅助函数，通过 `view.domAtPos` 解析选区起始位置对应的 DOM 节点并调用宿主回调

## Renamed
- `PaneRichEditor.vue` 的 prop `onSearchMatchElementFocus` → `onScrollElementIntoCenter`，语义更通用，可被 `selectLineRange` 与搜索匹配共用
- `Markdown.vue` 内部函数 `scrollSearchMatchElementIntoView` → `scrollElementIntoCenter`，反映其通用居中滚动职责
- `Markdown.vue` 模板传参 `:on-search-match-element-focus` → `:on-scroll-element-into-center`

  - Tiptap 行为（4 个）：验证 `commands.setTextSelection` 正确设置选区、`focus(null, { scrollIntoView: false })` 不触发 `scrollToSelection`、对照组证明默认 `focus()` 会通过 RAF 触发延迟滚动、已聚焦时 `focus()` 早返回不滚动

# 2026-07-24

## Added
- Widget 设计面板新增 CSS 源码编辑入口，可通过 Monaco 弹窗编辑并保存选中元素的 CSS model。

## Changed
- Widget CSS 源码编辑器默认以 `:root` 规则包裹声明，避免 Monaco 对裸声明提示 `{ expected`。
- Widget 元素文本横向对齐不再同步设置 `justifyContent`，避免影响元素内容主轴布局。
- Widget 动作面板展开/收起改为更从容的宽度过渡，并移除顶部展开按钮悬浮提示。
- 默认布局 ChatSider 改为常驻挂载并由自身处理打开/关闭宽度动画，隐藏态仅保留 `inert` 控制交互。
- BMonaco 弹窗不再响应编辑器内部保存快捷键，避免 Ctrl/Cmd+S 触发保存并关闭弹窗。
- 激活运行中的聊天历史会话不再展示删除操作区。
- 顶部标签右键菜单逻辑迁移到 HeaderTabMenu 组件内聚处理。
- 顶部标签页移除内部测试标识属性和菜单根节点强制 key。

## Fixed
- 修复 Monaco CSS 编辑时语言服务请求落到默认 worker 导致 `getFoldingRanges` 缺失的问题。

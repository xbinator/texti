# 2026-07-24

## Added

- 增加 Chat Agent 委派恢复、Primary 续接和 Checkpoint/Task 合作式取消基础的窄 IPC/preload 接口；尚未实现 Child Runtime `AbortSignal`、grace period 或 hard abort。
- 增加应用级 Checkpoint allowlist 事件、单调 cursor 去重和 renderer 重载恢复。
- 增加真实内存 SQLite 委派基础闭环测试，覆盖生产 Runtime A 挂起/Runtime B 续接、事务回滚、发布失败后 pending Outbox 与 `listActive` 持久化事实、Checkpoint CAS 和重启中断；当前没有自动 Outbox 重投器。
- 增加 Child Attempt 原子生命周期 Store API，统一创建、启动确认、幂等重放、谱系 Event 和 Attempt 历史查询，普通委派测试不再通过裸 SQL 启动 Child。
- 增加 Child 只读资源 realpath scope 解析与 Execution Plan 编译/恢复，能力严格取契约、父 Runtime、当前可用工具、registry、安全策略和资源 resolver 的交集。
- 增加只读 Task 原子授权 Store API，在一个事务内提交 `created → planning → authorized → queued(start)`、不可变计划和完整审计 Event。

## Changed

- Agent、Turn 与 Session Actor 增加 checkpoint-aware `waitingChildren` / `cancellingChildren` 状态。
- Primary Runtime B 改为 Main CAS 后立即确认启动，并由后台安全终态化 Checkpoint 与 continuation fence。
- `waiting_children` Runtime 完成原因改为等待投影，不再误报 Session 完成。
- Primary 续接增加 Runtime A 挂起栅栏、同 tuple 幂等对账、取消响应回退与可信 assistant 终态更新。
- cooperative cancellation 的 Renderer 输入收缩为 Checkpoint 身份，取消原因固定由 Main 持久化；当前只收敛 Checkpoint/Task 与 source assistant 状态，不宣称已终止尚未实现的 Child Runtime。
- 续接和取消的 transport-unknown 对账改为保留不可变 flight，并增加终态幂等响应、地址完整性校验、重试预算与 scope dispose 栅栏。
- Checkpoint 完成或失败可直接收口等待中的 Agent、Turn 与 Session，旧终态响应不会重新注册 Runtime route。
- 普通 Renderer Runtime 启动在取得锁和写消息前拒绝 `delegate_task`、伪 Child 身份与内部 lineage；Runtime B 同时保留执行派生和同 Actor 续接谱系。
- Renderer 重载时先查询活动 Checkpoint，避免把 `waiting_children` source assistant 误写为硬中断；Agent 状态查询失败时按 fail-closed 处理。
- Renderer 工具 controller 与 stream executor 共用同一个规范化超时配置。
- Execution Plan 切换到独立 `read-runtime-v1` policy，只允许本地主进程 direct `pure_read` 工具、非空权限/资源范围、继承 Checkpoint 模型和无写入 commit policy；恢复投影只能单调收缩。
- 连续 Execution Plan 恢复增加 previous-effective ceiling，终态 Task 不可恢复执行，通用状态迁移不能绕过 read Task 原子授权。
- 在父权限与层级预算账本完成前，生产默认 Child 授权保持 fail-closed，避免冻结可被拆分 Task 放大的伪预算；测试通过受信依赖注入显式授权上限。

## Features

- 等待 Child 的 Turn 保持忙碌且可发起合作式取消并等待 Checkpoint/Task 持久化收敛，不接受新用户输入，也不会误中止已释放的 Runtime A。
